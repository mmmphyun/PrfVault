# PrfVault Web Playground (과제 BR-B 실행 묶음)

논문 《국내 50대 웹사이트의 비표준 인증 보안 인터페이스가 브라우저 패스워드 매니저 및 암호 엔트로피에 미치는 영향 실증》의 실측 연구 결과를 대화형으로 직접 체감하고 활용하는 단일 정적 웹 애플리케이션입니다.

---

## 1. 누구를 어떻게 돕는가 (앱 한 문장)

> **"국내 웹 서비스를 이용하는 사용자가 네이버·KT의 16자 제한이나 금융권 가상 키패드 등 비표준 보안 인터페이스를 마주할 때, 본 앱이 사이트 제약을 자동 진단하여 94개 복합 문자군 기반 적응형 고엔트로피 비밀번호를 생성하고 가상 키패드용 1회용 마스킹 복사 및 Wasm 메모리 소거(Zeroize)로 계정을 보호해 준다."**

---

## 2. 사용자가 할 일 세 가지 (1분 체험 절차)

1. **[1단계: 도메인 제약 진단]**:
   - 상단의 빠른 선택 칩(네이버, KT, 삼성증권, 현대카드 등)을 클릭하거나 도메인을 직접 입력합니다.
   - 네이버/KT의 최대 16자 제한으로 인한 20.0%($26.22\text{ bits}$) 엔트로피 결손, 삼성증권/현대카드의 가상 키패드 차단 여부가 즉시 진단됩니다.
2. **[2단계: 적응형 고엔트로피 생성 및 실시간 엔트로피 비교]**:
   - 마스터 시크릿을 입력하고 `[적응형 고엔트로피 암호 생성]` 버튼을 누릅니다.
   - 16자 제한 사이트의 경우 94개 전체 복합 문자군을 가득 채워 엔트로피 상한치($104.87\text{ bits}$)를 보장하며, NIST 권고치($131.09\text{ bits}$) 대비 엔트로피 바 차트 및 GPU 오프라인 크랙 예상 시간이 실시간 계산됩니다.
3. **[3단계: 비표준 대응 마스킹 복사 & Wasm 메모리 물리 소거(Zeroize) 시연]**:
   - 가상 키패드 감지 시 `[1회용 마스킹 복사 & 5초 Zeroize 시작]` 버튼을 누릅니다.
   - 복사 후 5초 카운트다운 동안 WebAssembly 선형 메모리 상의 평문 바이트가 `prf_vault_dealloc_zeroize`를 통해 `0x00`으로 덮어씌워지는 실시간 헥스 덤프(Hex Dump) 변화(`Active` $\rightarrow$ `Zeroized`)를 확인하고, 하단 모의 로그인 폼에 붙여넣어 제출합니다.

---

## 3. 실행 방법 (새 임시 폴더에서 즉시 실행)

본 애플리케이션은 **외부 npm 패키지 설치나 백엔드 서버 없이 단독 실행**되는 순수 정적 웹 번들입니다.

### 방법 1: 브라우저 더블클릭 (가장 간단한 방법)
- 압축을 해제한 폴더의 `index.html` 파일을 더블클릭하여 Chrome, Edge, Firefox 등 최신 웹 브라우저로 엽니다.
- Wasm 코어가 Base64로 인라인 탑재되어 있어 로컬 `file:///` 환경에서도 CORS 오류 없이 즉시 구동됩니다.

### 방법 2: 로컬 웹 서버 실행 (선택 사항)
PowerShell 또는 터미널에서 다음 명령 중 하나를 실행합니다:
```powershell
# npx serve 사용 시
npx serve .

# 또는 Python 내장 웹서버 사용 시
python -m http.server 8000
```
웹 브라우저에서 `http://localhost:3000` 또는 `http://localhost:8000`에 접속합니다.

## 4. 데이터 및 비밀값 정책 (BRB-C06, BRB-C07 준수)

- **개인정보 0건**: 본 앱에 탑재된 도메인 50개 정보는 2026년 9월 28일 Playwright 자동화 스캐너로 수집한 공개 로그인 DOM 속성(`data/raw-scans.json`)이며, 실명·연락처·개인 계정 정보는 일체 포함되지 않았습니다.
- **비밀값 0건**: 외부 상용 AI API 키, 토큰, 비밀번호 등 어떠한 비밀값도 소스코드나 화면에 존재하지 않습니다. 모든 암호 연산과 엔트로피 연산은 브라우저의 Web Crypto API 및 로컬 Rust WebAssembly 바이너리 상에서 독립적으로 처리됩니다.
