### 재현·통과 확인 4가지
- **어디서 확인하나요**: 제출한 납품본 ZIP (`T10-PrfVault-Submission.zip`) 압축 해제 루트 폴더
- **무엇을 하나요(3단계 이내)**:
  1) `T10-PrfVault-Submission.zip`의 압축을 풀고 터미널에서 해당 폴더로 이동합니다.
  2) `node --experimental-strip-types scripts/benchmark/analyzer.ts --input=data/raw-scans.json --output=data/reproduced-analysis.json` 명령을 실행합니다 (별도 패키지 설치 불필요).
  3) `node --experimental-strip-types scripts/tests/analyzer.test.ts` 명령으로 수학 모델 및 대조군 집계 무결성 테스트(5건)를 실행합니다.
- **무엇이 보이면 통과**: 콘솔에 `PrfVault BENCHMARK QUANTITATIVE REPORT` 표(총 50개 스캔, MFA군 30개·가상 키패드 차단율 6.7%, 레거시군 20개, 최대 손실 `naver.com` 20%)와 `ALL 5 ANALYZER PIPELINE TESTS PASSED`가 출력되고 `data/reproduced-analysis.json`이 생성되면 통과입니다.
- **안 될 때**: Node.js 버전이 v22.6 미만인 경우 Node.js v22 LTS 이상을 사용하거나, 동봉된 `data/raw-scans.json`(원자료 50건)과 `data/benchmark-analysis.json`을 텍스트 에디터로 열어 `PAPER.md` 4장의 표 수치와 직접 대조하십시오.

### AI와 내 판단 3줄
- **AI에게 맡긴 일**: 50개 웹사이트의 원시 DOM 스캔 로그(`raw-scans.json`)를 파싱하여 8대 카테고리별 평균 엔트로피와 오프라인 GPU 크랙 시간($T = 2^{E-1}/R$)을 일괄 산출하는 TypeScript 분석 코드(`analyzer.ts`) 작성을 맡겼다.
- **내가 판단한 일**: 조사 대상을 MFA 의무화 규제군(30개소)과 단일 패스워드 레거시군(20개소)으로 대조 설계하고, 스캔 중 발생한 `card.kbstar.com` DNS 실패 1건을 삭제하지 않고 원자료에 보존하며, 전체 평균 손실률이 0.8%로 낮게 나온 데이터를 근거로 초기 전역 가설을 '초대형 포털·금융사 국소 병목 가설'로 직접 수정했다.
- **AI 말을 안 들은 일**: AI가 참고문헌으로 추천한 가짜 논문(*Kim & Lee, 2022*)을 원문 대조를 통해 할루시네이션으로 판별하여 즉시 삭제했고, 가상 키패드 사이트에서 보안 스크립트를 강제 우회(Hooking)하자는 AI의 코드 제안을 거부하고 비우회 원칙에 입각한 1회용 클립보드 폴백 구조를 고수했다.

## 2. 패키지 파일 구성

- `PAPER.md`: 완성 논문 원고 1편 (표지, 초록, 서론, 선행 연구, 방법, 결과, 논의 및 한계, 결론, 참고문헌 수록)
- `README.md`: 본 재현 패키지 안내서 및 체크리스트 매핑표
- `data/raw-scans.json`: 2026-09-28 수집 국내 50대 웹사이트 DOM 스캔 원자료 (50건)
- `data/benchmark-analysis.json`: 섀넌 정보 엔트로피 및 대조군 정량 분석 결과
- `scripts/package.json`: 스캐너 및 분석기 실행 스크립트 명세
- `scripts/benchmark/targets.ts`: 국내 50대 웹사이트 도메인 및 대조군(30:20) 메타데이터
- `scripts/benchmark/scanner.ts`: Playwright 기반 헤드리스 DOM 스캐너
- `scripts/benchmark/analyzer.ts`: 섀넌 정보 엔트로피($E = L \times \log_2 N$) 및 차단율 계산 엔진
- `scripts/tests/scanner.test.ts`: 스캐너 타깃 및 셀렉터 무결성 검증 테스트 (5건)
- `scripts/tests/analyzer.test.ts`: 엔트로피 수학 공식 및 대조군 통계 검증 테스트 (5건)
